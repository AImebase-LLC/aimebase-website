# aimebase-website

The website for [AImbase](https://aimebase.com), an AI product studio in South Portland, Maine, and its first product, AImdoc.

Built with Next.js, Tailwind CSS, and TypeScript.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Editing content

- Company info and copy: `src/lib/site.ts`
- Projects: `content/projects/*.md`, one file per project
- Brand logos: `public/brand/`

See `.env.example` for the contact form and booking link settings.
